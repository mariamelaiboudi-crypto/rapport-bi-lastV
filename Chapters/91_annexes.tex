\section*{Annexe A : Description des Données}

Le projet utilise deux fichiers de données principaux :

\begin{itemize}
    \item \textbf{employees.csv} : contient les informations générales des employés entre 2018 et 2024.
    \item \textbf{hr\_analytics.csv} : contient les indicateurs RH comportementaux et de performance.
\end{itemize}

Les principales variables analysées sont :

\begin{itemize}
    \item EmployeeID
    \item Department
    \item Salary
    \item Satisfaction Level
    \item Last Evaluation
    \item Average Monthly Hours
    \item Number of Projects
    \item Tenure Years
    \item Attrition Status
\end{itemize}

\section*{Annexe C : Architecture en Étoile (Star Schema)}

Le modèle de données suit une architecture Star Schema composée de :

\begin{itemize}
    \item \textbf{FactHR} : table de faits principale contenant les métriques RH.
    \item \textbf{DimEmployee} : informations des employés.
    \item \textbf{DimDepartment} : informations des départements.
    \item \textbf{DimDate} : gestion temporelle et analyse chronologique.
\end{itemize}

Cette architecture permet :
\begin{itemize}
    \item Une meilleure performance des requêtes DAX
    \item Une maintenance simplifiée
    \item Une modélisation professionnelle orientée Business Intelligence
\end{itemize}

\section*{Annexe D : Mesures DAX Principales}

\subsection*{Taux d'Attrition}

\begin{verbatim}
Attrition Rate =
DIVIDE(
    CALCULATE(
        DISTINCTCOUNT(FactHR[EmployeeID]),
        FactHR[left] = 1
    ),
    [Total Employees],
    0
)
\end{verbatim}

\subsection*{Taux de Rétention}

\begin{verbatim}
Retention Rate = 1 - [Attrition Rate]
\end{verbatim}

\subsection*{Score de Risque des Heures Supplémentaires}

\begin{verbatim}
Overtime Risk Score =
CALCULATE(
    DISTINCTCOUNT(FactHR[EmployeeID]),
    FILTER(
        FactHR,
        FactHR[average_monthly_hours] > 220
    )
)
\end{verbatim}

\section*{Annexe F : Principaux Insights Business}

Les analyses réalisées ont permis d'identifier plusieurs résultats importants :

\begin{itemize}
    \item Le département Sales présente le plus fort taux d'attrition.
    \item Les employés travaillant plus de 220 heures par mois sont fortement exposés au risque de départ.
    \item Le pic d'attrition apparaît entre 2 et 3 années d'ancienneté.
    \item Les employés performants mais sous-rémunérés quittent davantage l'entreprise.
    \item Un faible niveau de satisfaction est fortement corrélé au départ des employés.
\end{itemize}
